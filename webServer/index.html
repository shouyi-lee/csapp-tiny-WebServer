为什么这套文件可以直接使用

专门按 tiny-webserver 的静态资源方式组织

页面只使用浏览器原生能力，避免任何需要额外服务端支持的高级特性， 让你的 C 语言 WebServer 也能稳定提供前端页面。

纯静态资源

只包含 .html、.css、.js 三类文件，与你当前 MIME 映射完全兼容。

本地相对引用

HTML 中通过本地路径引用样式和脚本，不需要外网，也不需要 npm、打包器或构建流程。

默认首页可访问

你的服务器会把根路径映射到 /index.html，因此打开首页即可看到内容。

简单交互演示

提供主题切换、时钟更新与状态提示，方便验证 JavaScript 是否已经成功执行。

使用流程

三步完成本地访问

01

编译并运行服务端

在 csapp/tiny-server 中执行 make run，服务程序会在 webServer 目录内启动。

02

浏览器访问首页

打开 http://localhost:8080/，请求会自动落到 index.html。

03

验证静态资源加载

确认页面样式正常、按钮可点击、时钟在走动，说明 CSS 与 JavaScript 已成功加载。
